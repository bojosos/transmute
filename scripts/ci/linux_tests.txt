# The ctest tests the Linux CI job runs (.github/workflows/ci.yml, job "linux";
# scripts/ci/linux_ctest.py builds what they need and runs them). They are the
# tests that pass on Linux today, headless, with a clean environment
# (no session bus, no audio server, no display). alchemy_gui_host runs in its
# own step on Xvfb.
#
# Left out, with the reason (counts at 79dd8df0 + the Linux batch, 2026-11-10):
# - 53 test targets do not build on Linux: Windows-only test sources (the PE
#   loader, the Win64 ABI and SEH, the x64 JIT, the Win32 window server's
#   tables, ...).
# - 29 run their guests through the x64 JIT, which is built for Windows only
#   (src/jit_x64_unavailable.cpp elsewhere): alchemy_objc*, alchemy_threads,
#   the CF/Foundation/dispatch workloads, ...
# - 7 need an X display (they pass on a local Xvfb): alchemy_gui_window_events,
#   alchemy_gui_text_input, alchemy_gui_metal_triangle(_resize),
#   alchemy_gui_metal_iosurface_present, alchemy_gui_metalkit_view,
#   alchemy_gui_quartzcore_backingstore.
# - 3 pass Mach ports or IOSurfaces between processes, which needs descriptor
#   passing (SCM_RIGHTS) on Linux, not written yet: alchemy_fx_mach_cross,
#   alchemy_gui_metal_iosurface_cross, alchemy_gui_quartzcore_iosurface_cross.
# - 1 registers a Bonjour service (alchemy_gui_bonjour_fixture; it fails on
#   the Windows runner too).
# - 20 fail on Linux gaps still open, each a follow-up:
#   alchemy_fx_crash_report, alchemy_gui_appkit_controls_behaviour,
#   alchemy_gui_appkit_unit and alchemy_gui_appkit_windows_unit (Windows
#   paths in expectations), alchemy_gui_corefoundation_additions (the en_US
#   short date pattern), alchemy_gui_coreservices and
#   alchemy_gui_coretext_unit (case-insensitive compares),
#   alchemy_gui_coreservices_system_services, alchemy_gui_coretext_fonts and
#   alchemy_gui_framework_cases (they need C:/Windows/Fonts/arial.ttf),
#   alchemy_gui_devices (power messages), alchemy_gui_foundation_bundle_fixture,
#   alchemy_gui_foundation_runtime (enumerator order),
#   alchemy_gui_libsystem_foundation, alchemy_gui_libsystem_gaps (idle ticks),

#   alchemy_services, alchemy_services_process.
