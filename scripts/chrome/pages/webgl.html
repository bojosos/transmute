Alchemy WebGL smoke

A conformance-style WebGL smoke written for Alchemy (no downloaded suite). Each test draws into a 64x64 canvas (or a framebuffer object), reads pixels back and compares them with tolerances, and checks getError() after each step. WebGL 1 runs the first group; WebGL 2 runs it again plus float textures and instancing. The verdict goes into document.title (Alchemy WebGL: PASS or Alchemy WebGL: FAIL <test>) and into body[data-verdict]; each test's result is a row below (for --dump-dom).
