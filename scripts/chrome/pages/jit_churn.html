Alchemy JIT churn

Makes V8 compile and throw away machine code for a while, as long benchmarks do (Speedometer, JetStream): every round creates new functions with new Function, runs them hot enough for V8's optimizing tiers, and drops the oldest ones, so the garbage collector frees their code and V8 writes new code into the same pages. ?seconds=N sets the run time (default 120), ?batch=N the functions per round (default 64), ?keep=N how many stay alive (default 512). The title ends as Alchemy JIT churn: PASS ... or Alchemy JIT churn: FAIL ....
