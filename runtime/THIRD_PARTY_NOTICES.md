## Host tools and libraries referenced by the alchemy-fx GUI

The GUI providers (`ALCHEMY_WITH_GUI`, `cmake/AlchemyGui.cmake`) reference the
following third-party components. None is vendored, copied or redistributed by
this repository or its build; each is located on the build machine through a
CMake cache entry and, for the DLLs, loaded with `LoadLibrary` at run time.

| Component | Use | Cache entry | License |
| --- | --- | --- | --- |
| `libclang.dll` from LLVM 19.1.5 (Visual Studio's bundled x64 LLVM toolchain) | MSL front end of the MSL -> SPIR-V compiler, loaded at run time (`ALCHEMY_LIBCLANG` overrides the path) | `ALCHEMY_LIBCLANG_DLL` | Apache-2.0 WITH LLVM-exception |
| `clang-c` C API headers, LLVM 19.1.5 (`llvmorg-19.1.5`, the same tag as above) | Declarations of the libclang C API; build-time only | `ALCHEMY_CLANG_C_INCLUDE` | Apache-2.0 WITH LLVM-exception |
| Vulkan loader `vulkan-1.dll` (installed with the GPU driver or the Vulkan SDK) | Metal on Vulkan, loaded at run time | none | Apache-2.0 |
| Vulkan-Headers from the LunarG Vulkan SDK 1.4.357.0 | Vulkan API declarations; build-time only | `ALCHEMY_VULKAN_INCLUDE` | Apache-2.0 OR MIT |
| `spirv-val` from SPIRV-Tools (LunarG Vulkan SDK) | Validates compiler output in tests only | `ALCHEMY_SPIRV_VAL` | Apache-2.0 |

The Apple framework declaration headers under `runtime/include/{AppKit,Metal,
QuartzCore,CoreGraphics}` and the link-only fixture libraries under
`tests/fixtures/macos/link_*` are project-authored from the public interface
(selector names, structure layouts and enumeration values); they contain no
Apple header text or code.
